This prototype is to test the admin interface for managing forms, viewing submissions, and managing user access.

Starting Scenario 1 resets the current session to its defaults, with no form, uploaded logo, team members or submissions, then opens the start page.

Updated 27 October 2026: uploaded logos are shown on the form review page and saved in the current prototype session. Uploads are handled in memory, without creating image files on disk, with a 5 MB limit. Continuing without a new file keeps the saved logo; clearing prototype data removes it.

Hypotheses

Users are able to:

  • Create and publish a form
  • View and download submissions
  • Unpublish a form
  • Add a user

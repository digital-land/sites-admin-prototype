Iteration 01: view and download submissions

Updated 22 October 2026.

Start the view and download submissions flow

Starting this scenario resets the example submissions to one new submission and three downloaded submissions in your session.

  • View the dashboard count of new submissions.
  • Browse new and downloaded submissions and view their question-and-answer summary lists.
  • Simulate processing a CSV or GeoJSON of new submissions or all submissions.
  • When processing completes, the selected submissions move to Downloaded submissions and the dashboard count updates.

The examples use shared illustrative answers. Each submission shows a real London site boundary from OpenStreetMap as an example; the boundaries do not match the fictional addresses. Submission details include the same DEFRA interactive map used by the sites form prototype, with an Ordnance Survey basemap, zoom buttons and view-only boundaries.

To enable the basemap locally, set ORDNANCE_SURVEY_API_KEY in your environment or an untracked .env file and restart the prototype. Do not commit the key. Without the key or JavaScript, the submission details remain available.
